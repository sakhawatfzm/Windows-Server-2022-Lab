# Windows Server 2022 Administration Lab

This repository contains hands-on labs covering core and advanced Windows Server administration topics. Each lab is designed to provide practical experience with enterprise infrastructure and services.

## 1. Initial Setup & Virtual Machines
- Initial Lab Setup
  - Installing VMware
  - Installing Windows Server 2022
  - Installing Windows 10 Client

## 2. Active Directory Domain Services (AD DS)
- Installing Active Directory Domain Services
- Promoting a Server to a Domain Controller
- Joining a Windows Client to the Domain
- Creating Organizational Units (OUs) and User Accounts

## 3. DHCP & Windows Deployment Services (WDS)
### DHCP Server
- Installing and Configuring DHCP
- Creating and Managing DHCP Scopes
- IP Address Reservation
- DHCP Backup and Restore

### Windows Deployment Services (WDS)
- Installing and Configuring WDS
- Deploying Windows Images

## 4. Domain Controllers (Advanced)
- Root Domain Controller (Root DC) Setup
- Additional Domain Controller (ADC) Configuration and Replication
- Read-Only Domain Controller (RODC) Deployment
- Child Domain Controller (CDC) Setup
- Transferring FSMO Roles

## 5. File Server & Storage
### File Server Resource Manager (FSRM)
- Configuring Storage Quotas
- File Screening

### Distributed File System (DFS)
- Creating DFS Namespaces
- Configuring Namespace Permissions

## 6. Backup & Recovery
- Windows Server Backup
- Full Server Backup
- Restoring Deleted Active Directory Objects

## 7. Disk Management
### Basic Disk Management
- MBR vs GPT
- Partition Management
- NTFS vs ReFS

### Dynamic Disks & RAID
- Striped Volumes (RAID 0)
- Mirrored Volumes (RAID 1)
- RAID 5 Configuration

## 8. Advanced Server Features
### Failover Clustering
- iSCSI Storage Configuration
- Heartbeat Network Configuration
- Cluster Validation and Deployment

### Group Policy Management (GPO)
- Creating and Linking GPOs
- Security Filtering
- Blocking Inheritance
- GPO Management Best Practices
